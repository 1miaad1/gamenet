# گیم‌نت من — نسخه سروری

## امکانات نسخه ۱
- داشبورد موبایل
- ۲ PS4 + ۱ PC از پیش تعریف‌شده
- Start / Stop و تایمر زنده
- محاسبه مبلغ بر اساس نرخ ساعتی
- ذخیره دائمی در SQLite
- گزارش درآمد و زمان امروز
- تاریخچه بازی‌ها
- ثبت هزینه
- تغییر نام و نرخ هر دستگاه
- قابل اجرا روی VPS/هاست Node.js

## اجرا
Node.js 18+ نصب کنید:
npm install
npm start

سپس:
http://localhost:3000

برای انتشار عمومی، پروژه را روی VPS/Render/Railway/Fly.io یا سرویس Node.js مشابه قرار دهید و دامنه HTTPS متصل کنید.

## امنیت
نسخه اولیه ورود مدیر ندارد. برای استفاده واقعی روی اینترنت، قبل از عمومی‌کردن باید احراز هویت، HTTPS، بکاپ دیتابیس و محدودیت دسترسی API اضافه شود.
